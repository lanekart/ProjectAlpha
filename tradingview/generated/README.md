# Generated Pine Scripts

All six checked-in strategy variants are regenerated by:

`poetry run python -m alpha pine regenerate`

Do not patch these files manually. The exporter applies Pine-safe identifier
rewrites, configuration overrides, UTF-8/LF normalization, and strict static
validation before writing.

TradingView compilation and runtime smoke tests remain user-verification steps.

The `alpha pine export` command writes configured, self-contained Pine v6
scripts here. Generated files are deterministic for the same source commit and
configuration. They are research artifacts, not broker instructions.

Run `alpha pine validate` after generation. TradingView compilation remains a
manual acceptance step.

Ready-to-use JSON configurations are provided for positional, swing, and short
swing research. Pass one with `--config`; the strategy ID remains an explicit
`--strategy` argument.
